我是 Tran Huu Dang，一名全栈开发者，专注于使用 React、Next.js、Angular、Node.js、Spring Boot、PostgreSQL、MongoDB 和 Redis 构建现代化 Web 应用。

过去几年中，我参与了企业内部系统、管理平台以及服务数百名活跃用户的 Web 应用开发。我的经验覆盖前后端全流程，包括响应式界面设计、可扩展 API 构建以及数据库架构设计。

我经常使用实时技术，例如 WebSocket、Server-Sent Events (SSE)、webhook、后台任务、缓存策略和数据库优化技术，以提升系统性能与稳定性。

近期我也在深入探索 AI 应用开发，包括 RAG 流程、语义搜索、向量数据库、文档处理和 LLM 集成。我喜欢将 AI 能力落地到真实业务工作流和产品中。

除了软件开发，我也具备 Docker、Linux 服务器、Nginx、CI/CD 流水线以及云端部署的实践经验。我重视代码质量、可维护架构与持续学习。
