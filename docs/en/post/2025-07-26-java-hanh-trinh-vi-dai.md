> _"Write once, run anywhere"_ – Where did that famous slogan begin? And why did a programming language born from a failed project become the backbone of the global digital economy? Join me as I dig up the legendary story – equal parts technology and tragedy – of **Java**.

## ☕ A gentle start, like a hot cup of coffee

On an early winter day in 1990, in Shikul Valley, a group of engineers at Sun Microsystems (pronounced "Sun Micro-sis-tems," the Đang-approved pronunciation) began a secret project called "**Green Project**." The team hid away in a small office on Sand Hill Road – the holy land of venture capital. Their vision? To create a world where every electronic device would be _connected and interacting intelligently_ with one another.

![Green Team Office](/images/java-green-team.jpg)

## 🧠 The spark: James Gosling – father of Java

James Gosling – affectionately nicknamed "Horned Slasher" – was a Canadian programming genius, famous for his unruly hair and an IQ higher than the server room temperature. Together with Mike Sheridan and Patrick Naughton, he set out to create a new language, simpler and safer than C++.

They called it **Oak**, after spotting an oak tree outside their window.

![Oak Tree – The first name](/images/oak-tree.jpg)

## 🔁 From failure to destiny: HotJava and the Internet

The project nearly got the axe, until _the times created a hero_. The Internet exploded in 1993 with the arrival of the Mosaic browser. The Green team realized that Oak's "write once, run anywhere" philosophy fit perfectly with the fragmented world of the web.

They wrote a browser called **WebRunner** (later renamed **HotJava**) that could run small programs (applets) embedded in web pages. Java was reborn.

![HotJava Demo](/images/hotjava-demo.gif)


## ⚡ The fateful "Aha" moment — Java conquers the world at the 1995 Sun conference

In May 1995, at a Sun Microsystems conference in San Francisco, everything seemed calm until... **Java suddenly appeared**. Mid-presentation, the speaker abruptly switched over to a brand-new browser called **HotJava**.

Right there on stage, a 3D molecular model began spinning automatically in the browser — something **only expensive software could previously do**. The audience fell silent. Then, as if hypnotized, the whole hall erupted in applause.

> ✨ For the first time in history, an animated graphics program ran directly inside a web browser **without installing anything extra**. Java had done what seemed impossible.

That was the **historic moment**, the spark that turned Java from a "rejected child" into a **global phenomenon overnight**.

![Hot Java](/images/java-logo-early.jpg)

## ☕ Java is born in a coffee shop

Oak ran into a trademark conflict. During a brainstorming session at a coffee shop, they settled on a new name: **Java** – both the name of a coffee and a nod to energy, alertness, and... staying up all night writing code.

![First Java logo](/images/java-logo-early.jpg)

## 🔥 Java explodes: from applets to the enterprise

After a historic handshake with **Netscape**, Java was bundled into the most popular browser of the era. The "write once, run anywhere" story spread like wildfire across Silicon Valley. However, Microsoft felt threatened and... launched a legal war.

> 🤺 The "embrace, extend, extinguish" playbook was deployed: they embedded a JVM into IE, added proprietary features, and broke compatibility principles. Sun/Oracle sued. And they won.

![Java vs Microsoft](/images/java-vs-microsoft.jpg)

## 🏢 Java enters the enterprise world

Instead of dying, Java found another playground: **servers**.

Large systems – banks, airlines, governments – needed something stable, secure, and highly scalable. Java delivered on all three. Java Enterprise Edition (J2EE) was born and became the backbone of enterprise infrastructure.

> Ever bought a plane ticket, made a bank transfer, or registered for school online? There's a good chance you just passed through... Java.

![Java in the Enterprise](/images/java-enterprise.jpg)

## 📱 Java and phones: before the iPhone

Billions of Nokia and Motorola devices once ran Java ME – the app platform for feature phones. Remember the classic Snake game? That was Java too!

Later, when **Google acquired Android Inc.**, they chose Java as the main programming language for building the Android platform – helping turn it into the world's number one mobile operating system.

![Android Java](/images/android-java.png)

## ⚖️ Java vs Oracle vs Google

Oracle acquired Sun Microsystems in 2010 and sued Google for using Java APIs without permission. The lawsuit dragged on for more than 10 years and ended with a ruling in Google's favor.

> It wasn't just about money. It was a battle over the future of **software creativity**.

## 🧬 Java's legacy

Java is no longer just a programming language. It is:

- An open philosophy: write once, run anywhere.
- A community: millions of developers around the world.
- A platform: the JVM runs not just Java but also Kotlin, Scala, Groovy...

![Java Ecosystem](/images/java-ecosystem.jpg)

## 🎯 Conclusion: The rejected child becomes king

From a failed "toy" project, Java went on to:

- Conquer the Internet (Applets).
- Conquer the Enterprise (J2EE).
- Explode on Mobile (Android).

A long, rocky, yet brilliant journey. And... it's still not over.
